🚀 AWS Native CI/CD Pipeline Project

This website is automatically deployed using an AWS Native CI/CD Pipeline built with GitHub, AWS CodeConnections, CodePipeline, CodeBuild, and Amazon S3.

Every code change pushed to GitHub automatically triggers the pipeline, builds the application, and deploys the latest version to Amazon S3 without manual intervention.

Key Features

  • ✅ Continuous Integration (CI)
  • ✅ Continuous Deployment (CD)
  • ✅ AWS Native DevOps Services
  • ✅ Automated Build & Deployment
  • ✅ Amazon S3 Static Website Hosting
  • ✅ AWS CodePipeline Automation
  • ✅ AWS CodeBuild Integration
  • ✅ GitHub Source Control
